# Skill Portal

## 🛠 技术栈

- **框架**: Nuxt 3 (Vue 3)
- **语言**: TypeScript
- **样式**: TailwindCSS
- **数据库**: PostgreSQL
- **测试**: Vitest

## 🚀 如何启动项目

本项目使用 `pnpm` 作为包管理工具。

### 1. 环境变量准备（可选）
复制 `.env.example` 为 `.env` 并根据实际情况填写配置：
```bash
cp .env.example .env
```

### 2. 安装依赖
```bash
pnpm install
```

### 3. 启动开发服务器
```bash
pnpm dev
```
项目启动后，可以在浏览器中访问 `http://localhost:3000` 查看。

### 4. 其他命令
- `pnpm build`：构建生产版本
- `pnpm test`：运行单元测试
